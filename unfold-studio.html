Unfold Studio Uploader

A private tool by Alireza Toghiani for the YouTube channel Unfold Animated

Uses YouTube API Services

Unfold Studio Uploader is a set of scripts I run on my own computer to publish my own animated videos to my own YouTube channel. It isn't offered to anyone else.

What it does

  • Uploads my finished videos as private, then sets each one's thumbnail, English captions and publish time.
  • Adds each video to the right playlists on my channel.
  • Posts and pins one comment on each of my videos, and replies to comments on my videos.
  • Reads my own channel's statistics, so I can learn what works.

Your data

It only touches my own channel. It doesn't collect, store or share data about viewers or other channels. Details are in the Privacy Policy.

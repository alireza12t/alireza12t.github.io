Privacy Policy

Unfold Studio Uploader · Last updated November 10, 2026

Unfold Studio Uploader is a private tool that I, Alireza Toghiani, use to publish and manage videos on my own YouTube channel, Unfold Animated. It isn't offered to anyone else, and it has no other users.

What it uses

The tool uses YouTube API Services. By using anything connected to it, you also agree to the YouTube Terms of Service, and Google handles data as described in the Google Privacy Policy.

What data it accesses

  • My own channel's videos, playlists, captions and thumbnails, so it can upload and schedule my videos.
  • Public comments on my own videos, so it can post my pinned comment and reply to viewers.
  • My own channel's statistics, so I can see which videos work.

It doesn't access other channels' private data, and it doesn't collect personal information about viewers.

How data is stored and shared

  • The tool runs only on my own computer, with OAuth access to my own Google account. The access token stays on that computer.
  • Any statistics it reads are kept only for my own analysis.
  • Nothing is sold, shared with third parties or used for advertising.

Removing access

Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions. Revoking it stops the tool from reaching the account. Stored statistics are deleted on request, or within 30 days of revocation.
